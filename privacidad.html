Política de Privacidad

```

Última actualización: junio de 2026

Esta Política de Privacidad corresponde a la aplicación Farmacias de Turno Olavarría, desarrollada por Matías Bolzan.

Información general

Farmacias de Turno Olavarría es una aplicación informativa que permite consultar farmacias de turno en Olavarría, Provincia de Buenos Aires, Argentina.

La aplicación muestra información pública relacionada con farmacias de turno, como nombre, dirección y teléfono.

Uso de la ubicación

La aplicación puede solicitar acceso a la ubicación del dispositivo únicamente cuando el usuario utiliza la función para ver cuál farmacia de turno está más cerca.

La ubicación se usa solamente en ese momento para calcular la distancia aproximada entre el usuario y las farmacias disponibles.

La aplicación no guarda, no comparte y no vende la ubicación del usuario.

Datos personales

La aplicación no requiere registro de usuario, no solicita nombre, correo electrónico, documento, teléfono personal ni contraseñas.

La aplicación no recopila datos personales directamente del usuario.

Analíticas

La aplicación puede utilizar herramientas de analítica, como Google Analytics, para conocer estadísticas generales de uso, por ejemplo cantidad de visitas o uso general de la aplicación.

Estas estadísticas se utilizan para mejorar el funcionamiento de la aplicación y no se emplean para identificar personalmente al usuario.

Fuentes de información

La información sobre farmacias de turno puede provenir de fuentes públicas disponibles en internet. Los turnos pueden estar sujetos a cambios o imprevistos de último momento.

Se recomienda llamar a la farmacia antes de concurrir.

Enlaces externos

La aplicación puede incluir enlaces a servicios externos, como Google Maps, llamadas telefónicas o WhatsApp, para facilitar la navegación, comunicación o compartir información.

El uso de esos servicios está sujeto a sus propias políticas de privacidad.
```
